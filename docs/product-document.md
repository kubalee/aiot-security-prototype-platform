# 安防 AIoT 联动中枢产品文档

## 1. 产品概述

安防 AIoT 联动中枢面向园区、楼宇、仓储、物业和安保值守场景，用于接收安防 AI 设备上报的事件、汇聚实时视频、调用平台智能体完成风险研判，并联动门禁、广播、工单、巡检、通知等物联系统。

当前版本是高保真产品原型，前端使用本地 JSON 模拟接口。后端实现时可按 `public/api/api-mocks.json` 和 `docs/api-contract.md` 的字段契约对接。

## 2. 产品目标

- 将 AI 摄像机、边缘盒子、传感器等设备上报的信息统一接入平台。
- 通过平台 AI 对事件进行复核、风险判断和处置方案生成。
- 将研判结果同步给物联系统，触发门禁、广播、工单、巡检等联动。
- 将事件和处置进展通知到值班主管、运维人员、物业经理等相关人员。
- 提供 PC 指挥看板、移动端值班看板、统计分析页和接口契约页，支持产品评审和后端联调。

## 3. 用户角色

| 角色 | 主要诉求 | 核心操作 |
| --- | --- | --- |
| 值班主管 | 快速判断事件是否需要处置，确认闭环 | 查看事件、复核 AI 结论、执行建议动作、确认闭环 |
| 安保巡逻人员 | 接收任务并到现场处理 | 接收通知、查看位置、执行巡检或现场复查 |
| 运维负责人 | 保障视频、设备和接口可用 | 查看视频流、检查设备状态、处理离线和接口异常 |
| 物业经理 | 关注联动结果和人员响应 | 查看通知回执、跟踪工单和处置进展 |
| 后端研发 | 按前端契约实现接口 | 查看接口页、读取 JSON 示例、确认字段和状态码 |

## 4. 业务流程

1. AI 设备识别到安防事件，调用事件上报接口。
2. 平台生成事件编号，展示到指挥页事件队列。
3. 平台读取关联视频流，显示实时画面或快照。
4. 平台调用视觉复核智能体，确认事件可信度和误报可能。
5. 平台调用风险研判智能体，输出风险等级、原因和建议动作。
6. 平台调用处置方案智能体，生成物联动作和通知策略。
7. 平台向物联系统下发联动指令。
8. 平台创建人员通知任务，并跟踪 App、短信、电话外呼回执。
9. 值班人员在指挥页确认处置闭环。
10. 平台写入审计日志，供复查和追溯。

## 5. 页面范围

### 5.1 指挥页

指挥页是值班人员的主工作台，用于实时处置事件。

核心模块：

- 事件队列：展示当前事件、位置、置信度和等级。
- 视频流列表：切换当前可用摄像头。
- 实时视频：展示 HLS/FLV/WebRTC 播放画面或快照。
- 视频信息：默认收起，鼠标移入或点击后展示视频源、原始流、播放协议和播放地址。
- AI 研判：展示平台智能体给出的处置判断。
- 处置阶段：设备上报、AI 复核、风险决策、联动执行、复查闭环。
- 建议动作：点击后模拟执行处置建议，并更新事件状态。
- 物联系统联动：点击后模拟下发联动动作。
- 人员通知：点击后模拟通知触达。
- 交互操作日志：记录原型内的关键点击和状态变化。

关键交互：

- 点击事件队列项，切换当前事件和关联视频。
- 点击视频流，切换当前摄像头。
- 点击建议动作，更新 AI 研判文案并写入操作日志。
- 点击处置阶段，推进事件进度。
- 点击物联行，将状态更新为已执行。
- 点击人员通知，将状态更新为已通知。
- 点击人工确认闭环，将事件状态、联动状态、通知状态统一更新为闭环。
- 点击指标卡，跳转分析页并带入筛选语义。

### 5.2 分析页

分析页用于观察事件、视频、联动、通知和接口准备度。

核心模块：

- 事件总量：点击查看全部事件。
- 平均置信度：点击查看处理中事件。
- 实时视频流：点击返回指挥页视频区域。
- 接口准备度：点击进入接口页。
- 处置阶段分布：点击阶段后筛选事件。
- 事件等级分布：点击等级后筛选事件。
- 筛选结果：展示当前筛选下的事件列表，点击可返回指挥页定位事件。
- 最近操作：同步指挥页和分析页产生的操作日志。

### 5.3 接口页

接口页用于产品、前端和后端对齐接口契约。

核心模块：

- 接口统计：接口总数、后端接口、智能体接口、调用链路。
- 接口分组：按 `dashboard`、`video`、`event`、`agent`、`iot`、`notification`、`audit`、`governance` 分组。
- 接口详情：展示方法、路径、描述、所属领域和页面使用位置。
- 请求示例：展示 `requestExample` 或查询参数。
- 响应示例：展示 `responseExample`。
- 字段说明：展示字段名、类型、是否必填和说明。
- 状态码：展示成功、失败和异步处理中等状态。
- 调用链路：展示实时指挥看板和后端接口交付流程。

### 5.4 配置页

配置页用于维护原型中的接入配置。

核心模块：

- 视频流编辑：新增、编辑、启用、停用、删除视频流。
- API 编辑：新增、编辑、删除后端接口或智能体接口。
- 视频流列表：展示协议、原始流、播放地址和启用状态。
- 后端 API 列表：展示接口方法、路径、名称和字段模板。
- 智能体 API 列表：展示智能体调用路径和入参模板。

## 6. 接口清单

接口完整契约以 `public/api/api-mocks.json` 为准。当前原型覆盖 13 个接口。

| ID | Method | Path | 用途 |
| --- | --- | --- | --- |
| `dashboard-overview` | GET | `/api/dashboard.json` | 指挥看板汇总 |
| `video-streams` | GET | `/api/video-streams.json` | 视频流配置 |
| `event-ingest` | POST | `/api/security/events/ingest` | AI 设备事件上报 |
| `event-detail` | GET | `/api/security/events/{eventId}` | 事件详情 |
| `agent-vision` | POST | `/agents/vision-reviewer/invoke` | 视觉复核智能体 |
| `agent-risk` | POST | `/agents/risk-assessor/invoke` | 风险研判智能体 |
| `agent-plan` | POST | `/agents/response-planner/invoke` | 处置方案智能体 |
| `iot-command` | POST | `/api/iot/linkage/commands` | 物联系统联动指令 |
| `notification-task` | POST | `/api/notification/tasks` | 人员通知任务 |
| `notification-receipts` | GET | `/api/notification/tasks/{taskId}/receipts` | 通知回执查询 |
| `contacts` | GET | `/api/security/contacts` | 应急联系人 |
| `audit-logs` | POST | `/api/security/audit-logs` | 处置审计日志 |
| `api-catalog` | GET | `/api/api-catalog.json` | 接口目录 |

## 7. 数据对象

### 7.1 Event 事件

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 事件编号 |
| `title` | string | 事件标题 |
| `zone` | string | 所属区域 |
| `location` | string | 详细位置 |
| `cameraId` | string | 关联摄像头 |
| `severity` | string | `critical | warning | normal` |
| `confidence` | number | AI 置信度 |
| `progress` | number | 处置进度，0-100 |
| `stage` | number | 当前处置阶段下标 |
| `aiDecision` | string | AI 研判结论 |
| `recommendations` | array | 建议动作 |
| `detections` | array | 识别信号 |
| `linkage` | array | 物联动作 |
| `contacts` | array | 通知对象 |

### 7.2 Stream 视频流

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 视频流编号 |
| `name` | string | 摄像头名称 |
| `zone` | string | 所属区域 |
| `protocol` | string | 原始协议，如 RTSP |
| `endpoint` | string | 原始流地址，生产环境建议返回脱敏值或配置引用 |
| `playProtocol` | string | 前端播放协议，如 hls、flv、webrtc |
| `playUrl` | string | 浏览器可播放地址 |
| `snapshotUrl` | string | 快照地址 |
| `status` | string | `online | offline | degraded` |
| `enabled` | boolean | 是否启用 |

### 7.3 Linkage 联动动作

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 联动系统名称 |
| `target` | string | 联动目标 |
| `status` | string | `pending | running | done` |
| `label` | string | 前端显示状态 |

### 7.4 Contact 通知对象

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 人员姓名 |
| `role` | string | 职责 |
| `channel` | string | 通知渠道 |
| `status` | string | `pending | running | done` |
| `label` | string | 回执状态 |

## 8. 权限与审计

| 能力 | 值班主管 | 巡逻人员 | 运维负责人 | 物业经理 | 后端研发 |
| --- | --- | --- | --- | --- | --- |
| 查看指挥页 | 是 | 否 | 是 | 是 | 否 |
| 执行建议动作 | 是 | 否 | 否 | 否 | 否 |
| 下发物联指令 | 是 | 否 | 条件允许 | 否 | 否 |
| 发送人员通知 | 是 | 否 | 是 | 条件允许 | 否 |
| 确认事件闭环 | 是 | 条件允许 | 否 | 否 | 否 |
| 维护视频流 | 否 | 否 | 是 | 否 | 否 |
| 查看接口契约 | 是 | 否 | 是 | 否 | 是 |

审计要求：

- 事件上报、AI 复核、风险研判、联动下发、通知发送、人工闭环都需要写入审计日志。
- 审计日志至少包含 `eventId`、`actor`、`action`、`target`、`payload`、`createdAt`。
- 涉及视频流凭据时，前端不得展示明文密码。

## 9. 非功能要求

- PC 端优先支持 1440px 及以上宽度，保持三栏指挥布局。
- 移动端支持 390px 宽度，无横向溢出。
- 视频画面默认不被信息卡遮挡；详细信息通过 hover、聚焦或点击显示。
- 本地 mock JSON 必须是合法 UTF-8 JSON。
- 接口简表和完整接口契约必须保持 ID 覆盖一致。
- 真实 RTSP 凭据只能放在 `.env.local`，不得提交到公开仓库。

## 10. 验收标准

- 指挥页事件、视频、AI 研判、处置阶段、联动、通知均可见。
- 指挥页建议动作、阶段、联动、通知、人工闭环均可点击并产生状态变化。
- 分析页指标卡、阶段分布、等级分布均可点击筛选。
- 接口页能展示 13 个接口的请求示例、响应示例、字段说明和状态码。
- 配置页能新增、编辑、停用、删除视频流和接口条目。
- `npm test` 通过。
- `npm run build` 通过。
- 移动端无横向溢出。
